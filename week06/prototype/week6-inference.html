Turn evidence into a decision

Lab: audit an AI answer

1. Specify the story and design

For this lab, use the small simulated teaching dataset embedded in each R cell. It represents 40 before/after score changes. It is not student data and is not a randomized comparison group. A one-sample t-test of change against zero illustrates the test mechanics; this design alone cannot establish that the tonic caused an improvement.

2. Ask AI for a checkable analysis

Optional: copy the prompt below into your usual AI tool. Do not include student names, project records, or private data. If you skip AI, use the prepared code in the next step and the deliberately flawed response in Step 4.

Copyable AI prompt

I am studying before/after exam-score change in a simulated sample. Use base R and a two-sided one-sample t-test against zero. Report n, the mean change, a 95% confidence interval, the p-value, and the assumptions. Use the five-step process: story, estimate/plot, test and hypotheses, statistical interpretation, practical interpretation. Do not claim causation or treat the p-value as the probability that a hypothesis is true. Explain what I should check myself.

3. Run the analysis yourself

Run the supplied code. It is self-contained: you do not need to run an earlier cell first. Then change the confidence level to 0.99, run again, and compare the interval. Return to 0.95 before recording your final interpretation.

Change conf.level = 0.95 to conf.level = 0.99. A wider confidence interval reflects a more conservative coverage target; it does not change the data.

set.seed(606)
change <- round(rnorm(40, mean = 7, sd = 18), 1)
t.test(change, mu = 0, alternative = "two.sided", conf.level = 0.95)

4. Catch an overclaim

Deliberately flawed AI-style response

“A small p-value means the tonic probably works. The observed improvement proves the tonic caused higher scores, so the company should launch it now.”

5. Finish the five-step story

Use your actual R output. In five short bullets: state the story, describe your estimate or plot, name the test and hypotheses, interpret statistical evidence, and explain the practical decision. Refer to a five-point business threshold. You may conclude that more evidence is needed.
