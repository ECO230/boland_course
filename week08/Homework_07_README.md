# Homework 7: t-Tests and Wilcoxon Tests

This is the in-person version of Homework 7.

When you first open the project in Posit Cloud, run this command once in the R
Console:

```r
source("project_setup.R")
```

Open `Homework_07_IP.qmd`, complete the response fields and project analysis,
and render the finished document to `Homework_07_IP.pdf`. Submit the PDF in
Canvas.

The `data` folder contains all four project datasets. Change `project_file` to
the filename associated with your project.
