# Canvas rubric audit

This audit distinguishes rubric definitions from rubric-to-assignment
associations. A rubric appearing in the Canvas Rubrics area does not by itself
mean that it is attached to an assignment.

## Reference course

The Spring 2026 Section 12 export contains 13 rubric definitions and 12 graded
assignment associations:

| Assignment | Rubric |
|---|---|
| Homework 2: Exploratory Data Analysis | Homework 2 |
| Homework 3: Basic Data Visualization | Homework 3 |
| Homework 4: Project Pre Planning | Homework 4 |
| Homework 5: Hypothesis Tests | Homework 5 |
| Homework 6: Chi Squared Analysis | Homework 6 |
| Homework 7: t-Tests and Wilcoxon Tests | Homework 7 |
| Homework 8: ANOVA and Simple Linear Regression | Homework 8 |
| Analysis Project - Presentation | Oral Communication Rubric |
| Analysis Project - Slides | Slide Deck Rubric |
| Analysis Project - Code | Code Documentation Rubric |
| Project 2 - Research Proposal | Open Topic Case - Executive Summary |
| Project 2 - Research Proposal [Fixed Groups] | Open Topic Case - Executive Summary |

Homework 1 did not have a rubric in the reference export. The repository now
defines a 10-point Homework 1 rubric aligned to the current assignment prompt.

The Discussion Rubric and Open Topic Case - Outline existed only as
course-level bookmarked rubrics in the reference course. They were not grading
rubrics for a tracked assignment.

## Fall 2026 Section 4

A read-only Canvas API inventory captured before the Homework 1 repair on
September 7, 2026 found 13 rubric definitions and 14 associations. Twelve were
assignment associations matching the table above, all with `purpose: grading`
and `use_for_grading: true`. The other two were the expected course-level
bookmarks.

The selective Homework 1 repair was subsequently completed and verified. The
assignment now has five criteria totaling 10 points, uses the rubric for
grading, and is published while the course remains unpublished. Section 4 now
has 14 rubric definitions and 13 assignment grading associations, plus the two
course-level bookmarks. Existing Homework 2-8 and project rubric associations
were retained without duplication.

Pass/fail participation work, non-submission gradebook shells, and ungraded
preparation wrappers do not receive a detailed rubric unless a separate
instructional decision adds one.
