## Visualizing Data in R (Optional)

These optional examples show what is possible with `ggplot2`. They are an
additional challenge, not a requirement to create every project visualization
in R. Use the tool that best supports your analysis and communication goals.

### Revisit Lab 3 with Our Course Dataset

[Open the optional Lab 3 R companion in Posit Cloud](https://posit.cloud/spaces/3173/content/12970507).

We have already explored these visualization ideas in Lab 3. This companion
shows what they look like in R using the same Chicago crash sample as our
Tableau and Excel lab. It provides worked examples of seven visual forms,
including comparisons, time series, proportions, relationships, distributions,
and a point map.

Run `source("project_setup.R")` once in the Console, then open
`Lab_03_R_Companion_IP.qmd`. Run the chunks from top to bottom, or select
**Render** to see the complete guide with code and charts. Try changing one
part of an example to see how the result changes. This is optional practice,
not an additional graded assignment.
