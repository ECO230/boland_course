These recordings reproduce the t-test and Wilcoxon demonstrations from class.
Use the
[Download Guided Notes 5: Inferential Statistical Tests]({{ canvas_file_guided_notes_5_inferential_statistical_tests_docx_url }})
while watching.

[Open the current Inference Examples project in Posit Cloud]({{ inference_examples_url }})
to run and modify the demonstrated code.

The recordings introduce the method family and then demonstrate:

- `idt()` for an independent-samples t-test;
- `pst()` for a paired-samples t-test;
- `ost()` for a one-sample t-test;
- `idw()` for a Wilcoxon rank-sum test; and
- `psw()` for a Wilcoxon signed-rank test.

Follow the current course project and `eco230r` setup when an older interface or
package-installation step appears in a recording. Use the Week 8 interpretation
guide to connect the output to the five-step analysis process.
