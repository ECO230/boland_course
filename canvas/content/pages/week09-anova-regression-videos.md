These recordings reproduce the simple linear regression and one-way ANOVA
demonstrations from class. Use the
[Download Guided Notes 5: Inferential Statistical Tests]({{ canvas_file_guided_notes_5_inferential_statistical_tests_docx_url }})
while watching.

[Open the current Inference Examples project in Posit Cloud]({{ inference_examples_url }})
to run and modify the demonstrated code.

The first 2 recordings introduce and apply `slr()` to estimate a linear change
in a quantitative outcome. The final 2 introduce and apply `ano()` to compare a
quantitative outcome across more than 2 groups.

Follow the current course project and `eco230r` setup when an older interface or
package-installation step appears in a recording. Use the Week 9 ANOVA and
regression interpretation guide to connect the output to the five-step analysis
process.
