Use these optional Microsoft resources when you need an Excel refresher:

- [Create a PivotTable to analyze worksheet data](https://support.microsoft.com/en-US/Excel/get-started/create-a-pivottable-to-analyze-worksheet-data)
- [Import or export text and CSV files](https://support.microsoft.com/en-us/office/import-or-export-text-txt-or-csv-files-5250ac4c-663c-47ce-937b-339e391393ba)
- [Save an Excel workbook](https://support.microsoft.com/en-us/office/save-your-workbook-92e4aae0-452d-497f-a470-570610ff720a)
- [Overview of Excel tables](https://support.microsoft.com/en-us/office/overview-of-excel-tables-7ab0bb7d-3a9e-4b56-a3c9-6c94334e492c)
- [Sort data in a range or table](https://support.microsoft.com/en-US/Excel/sort-data-in-a-range-or-table-in-excel)
- [Filter data in a range or table](https://support.microsoft.com/en-us/office/filter-data-in-a-range-or-table-01832226-31b5-4568-8806-38c37dcc180e)
- [Use XLOOKUP](https://support.microsoft.com/en-gb/office/xlookup-function-b7fd680e-6d10-43e6-84f9-88eae8bf5929)

::: {.callout-important appearance="minimal" icon="false" title="Preserve workbook features"}
After importing a `.csv`, save your working file as an Excel workbook (`.xlsx`).
A `.csv` cannot retain PivotTables, formulas, multiple worksheets, charts, or
formatting.
:::
