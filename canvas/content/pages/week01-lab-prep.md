## Lab 1 Preparation: Excel Tables, Sorting, and Filtering

Complete this preparation before class. Bring the saved Excel workbook to Lab
1 because the in-class activity builds on these skills. This preparation uses
a small Olist order sample; the in-class Lab 1 activity is the separate Posit
Cloud certificate project.

1. Read Microsoft's guide to [importing `.txt` and `.csv` files into Excel](https://support.microsoft.com/en-US/Excel/get-started/import-or-export-text-txt-or-csv-files).
2. [Download the Lab 1 preparation dataset]({{ lab_01_data_url }}). It contains
   600 delivered orders sampled from six Brazilian states.
3. Open the `.csv` file in Excel and confirm that its columns and values were
   imported correctly.
4. Save a working copy as an Excel workbook (`.xlsx`). See [Save Your Workbook](https://support.microsoft.com/en-us/office/save-your-workbook-92e4aae0-452d-497f-a470-570610ff720a)
   if you need help.
5. Convert the data into an official Excel table. See [Create and Format Tables](https://support.microsoft.com/en-us/excel/get-started/create-and-format-tables).
6. Use a table header to sort one quantitative field from largest to smallest.
7. Apply a filter to retain one meaningful category from a categorical field.
8. Clear the filter and confirm that all rows return.
9. Save the workbook again and be ready to open it at the start of Lab 1.

::: {.callout-note appearance="minimal" icon="false" title="Preparation is not the in-class lab"}
Complete these steps before class. During class you will complete the separate
Lab 1 Posit Cloud certificate activity.
:::

Use [Sort Data in a Range or Table](https://support.microsoft.com/en-us/excel/sort-data-in-a-range-or-table-in-excel)
and [Filter Data in a Range or Table](https://support.microsoft.com/en-us/office/filter-data-in-a-range-or-table-01832226-31b5-4568-8806-38c37dcc180e)
for additional help.
