Use this short recording if a downloaded Tableau workbook does not open as
expected.

Before troubleshooting, confirm that the file ends in `.twbx`. A packaged
workbook contains the workbook and its local supporting data. Open Tableau,
choose **File > Open**, and select the downloaded file. If Windows or macOS
changed the filename or added `.zip`, restore the `.twbx` extension first.

For additional help, see Tableau's
[Packaged Workbooks](https://help.tableau.com/current/pro/desktop/en-us/save_savework_packagedworkbooks.htm)
documentation.
