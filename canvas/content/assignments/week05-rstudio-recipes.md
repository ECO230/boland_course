## Purpose

Practice adapting working R examples. Some recipes go beyond the statistical
tests used later in the course; the goal is exposure and productive practice,
not completing every example without help.

Watch the orientation video above before beginning. The Week 2 **Video
Tutorials: R / Posit Cloud** page contains additional demonstrations if you
need a refresher.

## Practice

1. [Open the Practice R Coding project in Posit Cloud]({{ practice_r_coding_url }}).
2. Open the unsolved practice document and render it once before making
   changes. This confirms that the starting project works.
3. Copy a working example, run it, and then alter it to answer a prompt or
   explore something useful for your group project.
4. If an example does not work, read the error, compare your code with the
   original, and document what you tried. Getting stuck is part of the
   exercise.
5. Use the solved document or the worked-example video when you need another
   model. You may copy and adapt working code; make sure you understand what
   the revised code does.

## Submission

Submit a short text response in Canvas that answers both questions:

1. Which 3 examples did you alter successfully? If you did not complete 3,
   describe the examples you attempted and what happened.
2. Which 3 concepts were most difficult or still need clarification?

An answer of "none completed" can still earn credit when it describes a real
attempt. "I did not try" does not meet the assignment requirements.
