## Purpose

Set up the three tools used in ECO 230 and complete the Posit Cloud orientation
that produces your Lab 1 certificate: Excel, Tableau, and Posit Cloud.

## Complete the setup

1. Review [software available to UWL students](https://kb.uwlax.edu/147758)
   and confirm that you can open the desktop version of Excel. Excel for the
   web may work for some activities, but classroom demonstrations use the
   desktop application.
2. On that UWL software page, find **Tableau** and follow the **Tableau for
   Students** link. Use that route to create or activate your student
   account/license and install Tableau on your computer. Tableau is also
   installed on campus PCs if you cannot install it locally.
3. Create or sign in to your [Posit Cloud](https://posit.cloud/) account using
   your UWL email address.
4. [Join the ECO 230 Posit Cloud space]({{ posit_cloud_join_url }}).
5. [Open Lab 1: Technology Setup in Posit Cloud]({{ lab_01_posit_cloud_url }}).
6. Complete the project during class and generate the completion certificate.

## Submission

Submit the following in Canvas:

1. Upload the completion certificate as a PDF.
2. Paste the completed checklist into the submission comment and describe any
   problems you encountered. Write `No problems` if every step worked.

Text Entry is enabled as a backup if the PDF upload fails. If you use it,
explain the upload problem and attach the certificate on a later attempt.
