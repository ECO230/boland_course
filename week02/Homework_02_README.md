# Homework 2: Exploratory Analysis

This is the in-person version of Homework 2.

When you first open the project in Posit Cloud, run this command once in the R
Console:

```r
source("project_setup.R")
```

Open `Homework_02_IP.qmd`, complete the tables and response fields, and render
the finished document to `Homework_02_IP.pdf`. Submit the PDF and any required
supporting files in Canvas.

The `data` folder contains all four project datasets. Change `project_file` in
the assignment to the filename associated with your project.
