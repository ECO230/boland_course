# Guided notes

These editable Word documents are the student versions recovered without
modification from the Spring 2026 Section 12 Canvas export. The normalized
filenames make their week and topic clear; the document contents remain the
original exported files.

`Guided_Notes_01_Data_Literacy.docx` supports the only guided-notes assignment
students submit. It is a 5-point pass/fail Canvas file-upload assignment. The
remaining documents are delivered through non-graded Canvas items with no
submission, matching the reference course.

The legacy course uses two documents numbered Guided Notes 4: Communicating
Data and Hypothesis Testing. Their filenames preserve that numbering so the
documents continue to match the course material.

To reproduce these files from a local Canvas export, run:

```powershell
& .\canvas\scripts\extract-guided-notes.ps1
```

The `.imscc` input is intentionally excluded from Git. The extracted `.docx`
files are course resources and should remain tracked.
