Lab 3 Hints

Field placements and checks for the in-class demo

Before you build

Use this quick reference alongside the Lab 3 Video Guide: Tableau and Excel in Canvas. The videos show the full click-by-click walkthrough; these hints show where fields go and which transformations to check.

Connect to chicago_traffic_crashes_sample.csv. Keep crash_id as text, crash_datetime as date/time, and weather measurements and coordinates as numbers with decimal precision. Assign Latitude and Longitude geographic roles to the matching coordinate fields.

Crash count below means Tableau’s generated table Count measure. Place it on Text in a blank sheet: the unfiltered total should be 12,000. Do not sum crash_id. Each row is one sampled crash.

TipRead the pill before the chart

Check the aggregation (Count, SUM, or AVG), date level, and filters on each sheet. Blue means discrete and green means continuous; this is separate from dimension versus measure. Keep sheet-specific filters local.

1) Ranking

Question: Which reported causes appear most often?

Tableau location Field or setting
Rows primary_contributory_cause
Columns Crash count
Marks Bar; crash count on Label if useful
Filters Exclude missing causes, UNABLE TO DETERMINE, and NOT APPLICABLE

Transform: Sort by count descending. Select the ten largest remaining bars and Keep Only, as in the demo. This is a fixed selection, not a dynamic Top N rule.

Check: Ten causes remain; bar lengths are crash counts. Keep this selection on Ranking only.

2) Nominal comparison

Question: How does average injury count differ across causes?

Tableau location Field or setting
Rows primary_contributory_cause
Columns AVG(injuries_total)
Marks Bar; crash count on Tooltip
Filters Crash count: At least 30; exclude NOT APPLICABLE

Transform: Duplicate Ranking, then remove its cause selection. Replace count with injuries_total, change Measure > Average, and sort by average.

Check: The pill says AVG, not SUM. Label the axis Average injuries per crash. Inspect the count behind an average; the 30-crash cutoff does not make every group equally reliable.

3) Time series

Question: How do monthly crash counts change over time?

Tableau location Field or setting
Columns crash_datetime: continuous Month (green)
Rows Crash count
Marks Line; reported_weather_condition on Color
Filters Exclude CLEAR to match the saved demo; UNKNOWN is an optional exclusion

Transform: Use month-year positions on a continuous timeline. A discrete month name can combine January across different years.

Check: Dates run chronologically across years. State which weather conditions were excluded; counts in this sample are not crash rates.

4) Part-to-whole

Question: Within each quarter, what share belongs to each injury category?

Tableau location Start with a text table Then make stacked bars
Columns crash_datetime: discrete Quarter (blue) Keep Quarter
Rows most_severe_injury Crash count with Percent of Total
Marks Crash count on Text Bar; most_severe_injury on Color
Filters Exclude null injury categories Keep the same exclusion

Transform: Apply Quick Table Calculation > Percent of Total to count. In the text table, compute Table (Down). After moving fields, recheck: address most_severe_injury and partition by Quarter using Specific Dimensions. The denominator is the included crashes within each quarter.

Check: Every complete quarter totals approximately 100%. Discrete Q1-Q4 combines the same quarter across years.

ImportantHide is different from Exclude

First verify the complete 100% stacks. Then practice Hide on NO INDICATION OF INJURY and REPORTED, NOT EVIDENT, as in the demo. They still contribute to the table-calculation denominator, so visible portions total less than 100%. Exclude would instead recalculate shares among remaining records. Label the reduced display and show hidden categories again to check the full total.

5) Relationship

Question: How are temperature and dew point related?

Tableau location Field or setting
Columns weather_station_name, then temperature_f
Rows dew_point_f
Marks Circle; reduce opacity
Filters Exclude null station names

Transform: Turn off Analysis > Aggregate Measures for individual observations, matching the demo. Alternatively, a unique crash_id on Detail separates crashes while keeping aggregation on.

Check: You should see many marks, not a single SUM point. Label both axes in degrees F. Several crashes can share the same station-hour observation.

6) Distribution

Question: How does temperature vary across reported weather conditions?

Tableau location Histogram exploration Box-plot comparison
Columns temperature_f (bin) temperature_f
Rows Crash count reported_weather_condition
Marks Bar Individual observations with a box plot

Transform: Select temperature and use Show Me > Histogram; edit its bin size (try 5 degrees F). For box plots, start a fresh sheet, turn off Aggregate Measures or add crash_id to Detail, then add Box Plot from Analytics. Keep the histogram on a duplicate sheet if desired.

Check: Box plots summarize individual observations, not one average per category. Compare medians, the middle 50%, spread, and unusual points. Use temperature_f, not visibility, for this demo.

7) Map

Question: Where are the sampled crashes located?

Tableau location Field or setting
Columns longitude
Rows latitude
Marks Map/circle; crash_id on Detail; trafficway_type on Color

Transform: Keep aggregation on and use the crash ID to separate marks, as in the completed workbook. Adjust size and opacity. A ZIP-code filled map is an optional extension; it changes a mark from a crash to an area.

Check: Points fall around Chicago. Investigate null coordinates. Document any subset filter; more sampled crashes does not automatically mean greater risk per traveler.

Excel reminders

Reproduce at least three views using matching filters and aggregations.

  • Ranking: PivotTable Rows = cause; Values = Count of crash_id.
  • Nominal: Rows = cause; Values = Average of injuries_total plus crash count. Use the same count-at-least-30 and NOT APPLICABLE restrictions.
  • Time: Group dates by Years and Months; Values = crash count.
  • Relationship: Use a regular XY Scatter chart of raw temperature (X) and dew point (Y), not a PivotChart.
