# Homework 3: Visualizing Data

This is an optional Posit Cloud workspace for the required Homework 3.
You may instead use Excel or Tableau and assemble your Word or PDF document
outside Posit Cloud. The assignment requirements are the same for every tool.

If using this workspace, run `source("project_setup.R")` once in the R Console.
Open `Homework_03_IP.qmd`. Choose a CSV from `data`, create three visuals,
and insert each visual with its 3-5 sentence explanation. Add the summary
(no more than 200 words) and required AI reflection (4-6 sentences).

Render to `Homework_03_IP.pdf`. Confirm all three visuals appear inside the PDF.
Submit it in Canvas with your QMD and supporting image files, plus `.xlsx` or
`.twbx` files if you used those tools. Do not submit a summary without the visuals.
