Does Cool_Time fit the expected model?

In the lab, goodness of fit asks whether one categorical variable follows specified proportions. Use the same tea_tab data and equal-share model as the interpretation deck.

Lab: explain an association

Steps 1-3: Story, estimate, and hypotheses

The lecture asks whether injury status is associated with reported lighting condition in Chicago crashes. Both are categorical, so the lecture uses csi(injury_crash ~ reported_lighting_condition). Homework 6 applies the same logic to cleaning-fee status and bathroom category in Chicago Airbnb listings.

Compare the share of listings charging a cleaning fee within each bathroom category. Homework 6 restricts the analysis to listings with one to two bathrooms so categories with very few records do not drive the result.

  • H0: Cleaning-fee status is not associated with bathroom category.
  • HA: Cleaning-fee status is associated with bathroom category.
  • Alpha: 0.05.

Inspect the Homework 6 output

Run the same code used in Homework 6. The browser file retains the two columns this test needs and every row from the homework file. For the interpretation questions and feedback demo, use the starter code’s results.

Each column percentage uses the total for that bathroom category. A positive standardized residual indicates more listings than expected under independence in that cell; a negative residual indicates fewer.

Step 4: Statistical interpretation

What does the result say about the evidence against H0? Use the test statistic, degrees of freedom, and p-value. Name both variables. If the p-value and Bayes factor point in different directions, report both.

Step 5: Practical interpretation

How large and consequential is the result for a general business audience? Use the column percentages, standardized residuals, and effect size. A Bayes factor addresses strength of evidence; it is not an effect size.

Feedback demo

What feedback can check

Example draft: “The p-value proves bathroom count causes cleaning fees. Since the result is significant, owners should change their policy.”

Example coaching response

  • What works: You noticed the p-value is below 0.05.
  • What to revise: The test does not establish causation or practical importance. Compare the fee percentages and use Cramer’s V and the Bayes factor to qualify your interpretation.
  • Try again: What would you check about comparable listings before changing a fee policy?

That response is a written example. The tutorial’s checks and model answers run locally; no AI model is connected. For personalized feedback, build a prompt from your own draft below and optionally paste it into an AI tool you already have access to. Do not enter names or private project records.
