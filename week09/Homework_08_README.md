# Homework 8: ANOVA and Simple Linear Regression

This is the in-person version of Homework 8.

When you first open the project in Posit Cloud, run this command once in the R
Console:

```r
source("project_setup.R")
```

Open `Homework_08_IP.qmd`, complete the response fields and project analysis,
and render the finished document to `Homework_08_IP.pdf`. Submit the PDF in
Canvas.

The `data` folder contains the four project datasets and the larger Airbnb file
used by the worked examples. Change `project_file` to the filename associated
with your project.
