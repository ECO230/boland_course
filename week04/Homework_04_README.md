# Homework 4: Project Story Planning

This is the in-person version of Homework 4.

When you first open the project in Posit Cloud, run this command once in the R
Console:

```r
source("project_setup.R")
```

Open `Homework_04_IP.qmd`, complete all five story plans, and render the finished
document to `Homework_04_IP.pdf`. Submit the PDF in Canvas and keep it available
for the in-class group discussion.

The `data` folder contains all four project datasets.
